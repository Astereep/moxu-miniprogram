# moxu-miniprogram

# 模序 — 工业模型手工制作辅助小程序
> 工业设计毕业设计项目｜微信原生小程序
面向工业设计学生、手板制作者，用于油泥模型、3D打印后处理、树脂浇筑、板材拼装的工序管理辅助工具

## ✨ 功能介绍
- 模型项目管理，支持自定义工序，内置两套预制工序模板（油泥模型 / 光敏树脂后处理）
- 工序绑定倒计时打卡，记录固化、打磨等待时长
- 内置静态材料工艺库：油泥 / PLA / 光敏树脂 / ABS板 / 亚克力 / 补土等，包含收缩率、砂纸梯度、粘接方案、安全提示
- 缺陷修复手册：层纹、划痕、气泡、缩痕、流挂等模型常见故障的成因与修复方案
- 工序图文笔记记录、微信原生分享、导出工序清单图片

## 🛠 技术栈
WXML + WXSS + JavaScript
- 存储：小程序本地 `wx.setStorage`，**无后端、无爬虫、不请求外部接口**
- 部署：微信小程序测试号，免费预览，无需企业认证

## 🚀 运行方式
1. Clone / Download ZIP 下载全部源码
2. 打开【微信开发者工具】，导入项目，选择仓库根目录
3. 切换为【小程序测试号】即可真机扫码预览

## 📌 项目说明
本项目采用AI辅助原型验证的设计流程：由本人完成用户调研、需求定义、交互草图推导与设计决策；借助AI完成前端界面与代码落地，用于毕业设计原型验证，不作为商用项目。

## 📎 配套拓展概念
配套实体拓展设计：油泥工具收纳板，板上印刷工序二维码，扫码直接跳转小程序对应工艺页面，实现实体工作台和数字辅助工具联动。
